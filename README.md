# Customer Churn Analysis Dashboard 📉

An interactive Power BI dashboard designed to analyze customer attrition (churn) patterns, identify high-risk segments, and provide data-driven recommendations for improving retention.

## 🚀 Project Overview
This project focuses on identifying the key drivers behind customer churn. By analyzing demographic data, service usage, and contract types, the dashboard helps business stakeholders visualize "where" and "why" customers are leaving, enabling proactive retention strategies.
